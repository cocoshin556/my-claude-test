# 流生命 解釈データ（原典）

このディレクトリには流生命の**解釈テキスト**を JSON で格納する。

## 絶対原則
- コード（`src/lib/ryuseimei/`）は「タイプ番号」「サイクル」などの **枠の機械判定のみ** を行う。
- 解釈文は **絶対にコードで生成しない**。必ずこの `*.json` を参照する。
- 該当データが無い場合は捏造せず、UI で「**原典データ未登録**」と明示する
  （`Interpretation.found = false` / `text = null`）。

## 現状
**原典データ未登録**。原典に基づくデータは後から手動で投入する。

## 想定するデータ契約（型 `Interpretation` に対応）
解釈エントリは最低限このかたちを持つ：

```jsonc
{
  "title": "タイプ◯◯",      // 見出し（任意）
  "keywords": ["..."],        // 補助情報（任意）
  "text": "解釈本文"          // 本文（未登録なら投入しない＝found=false 扱い）
}
```

ファイル分割（例: `types.json` / `cycles.json` など）と具体的なキー設計は、
手順6で枠判定ロジックを確定させる際に、原典の確定部分に合わせて決める。
