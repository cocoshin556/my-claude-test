# 流生命 解釈データ（原典）

コード（`src/lib/ryuseimei/`）は原典「流生命の図」「流生命の出し方」に基づき、
**星（タイプ）とサイクルという機械判定できる "枠" のみ**を算出する。
解釈文（各星の性格・運勢など）は**絶対にコードで生成せず**、この `*.json` を参照する。
該当データが無ければ捏造せず「**原典データ未登録**」と明示する（`found=false` / `text=null`）。

## 出し方（実装済み・確定）
誕生年・月・日それぞれの**末尾**を足し、合計の**末尾(0-9)**が星番号。
- 例: 1975-10-02 → 5+0+2=7 → 空流生
- 例: 1968-08-19 → 8+8+9=25 → 末尾5 → 天流生

## データ（未登録）
**原典データ未登録**。各星の解釈は後から手動で投入する。

- 星の解釈: `stars.json`（予定）。`RyuseimeiStarId` をキーに `Interpretation` 互換のエントリ。
- サイクルの解釈: `cycles.json`（予定）。
- **サイクル判定ルールは現資料に無いため未実装**（`value=null`）。性別の関与もここで確定する想定。
